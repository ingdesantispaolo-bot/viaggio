CARTELLA MODELLI 3D ESTERNI (GLB / GLTF) - THE LONG MERIDIAN
================================================================================

Inserisci in questa cartella i file 3D in formato .glb o .gltf scaricati
(ad esempio da Sketchfab, CGTrader o esportati da Blender).

Godot 4.3 carichera' AUTOMATICAMENTE il modello esterno sostituendo quello
procedurale se il file corrisponde a uno di questi ID:

- fiat_127.glb           -> Fiat 127 Special (1974)
- panda_4x4.glb          -> Fiat Panda 4x4 Steyr-Puch (1983)
- renault_4.glb          -> Renault 4 GTL (1980)
- delta_integrale.glb    -> Lancia Delta HF Integrale Evo (1991)
- golf_gti_1990.glb      -> Volkswagen Golf GTI Mk2 (1990)
- mercedes_gwagen.glb    -> Mercedes-Benz G-Wagen W460 (1985)
- bmw_320_e30.glb        -> BMW 320i E30 Coupé (1988)
- lancia_stratos.glb     -> Lancia Stratos HF Stradale (1974)
- fiat_131_abarth.glb    -> Fiat 131 Abarth Rally (1976)
- alfa_gta.glb           -> Alfa Romeo Giulia Sprint GTA (1965)
- lancia_aurelia.glb     -> Lancia Aurelia B20 GT (1953)
- fiat_topolino.glb      -> Fiat 500A Topolino (1936)
- alfa_8c.glb            -> Alfa Romeo 8C 2900B Berlinetta (1938)
- mercedes_a250.glb      -> Mercedes-Benz A250 (2020)

Note di esportazione ottimali da Blender:
- Orientamento: asse Z in avanti / Y in alto (+Z forward o -Z forward)
- Scala: 1 unita' = 1 metro
- I materiali PBR incorporati (Albedo, Metallic, Roughness, Normal) vengono
  riconosciuti automaticamente da Godot 4.3 Forward+.
